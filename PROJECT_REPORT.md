# PROJECT REPORT
## Compare GitHub, GitLab, and Bitbucket by Managing a Sample Software Project

### Abstract
This project uses one Student DevOps Task Manager application to demonstrate modern DevOps practices and compare GitHub, GitLab and Bitbucket. It covers source control, branching, collaboration, automated testing, Docker and CI/CD.

### Objectives
- Build a working sample application.
- Use Git for version control.
- Demonstrate feature branches and code review.
- Automate tests.
- Containerize with Docker.
- Compare GitHub Actions, GitLab CI/CD and Bitbucket Pipelines.

### Technologies
Python, Flask, HTML, CSS, Git, GitHub, GitLab, Bitbucket, Pytest, Docker and YAML.

### Application
Students can add tasks and mark them complete. `/api/health` provides a health check for automation.

### DevOps flow
Developer -> Git -> Remote Repository -> CI/CD -> Tests -> Docker Build -> Deployment Ready

### Platform comparison
GitHub is strong for its large developer/open-source ecosystem and GitHub Actions.
GitLab is strong as an integrated DevOps platform with built-in CI/CD.
Bitbucket is strong for teams already using the Atlassian ecosystem and Jira.

### Conclusion
The fundamental workflow is the same on all three:
Code -> Commit -> Branch -> Review -> Test -> Build -> Deploy.
The major differences are tooling, integrations, ecosystem and workflow.
